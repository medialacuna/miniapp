# scratch-analyst — бот-анализатор Telegram-каналов с платными токенами

MVP: aiogram 3.x + Telethon + Ollama/OpenAI + SQLite + Telegram Stars.

## Модель монетизации

- 1 анализ канала = 10 токенов
- 100 токенов = 100 ⭐ (~$2)
- 500 токенов = 400 ⭐ (скидка)
- 1500 токенов = 1000 ⭐
- 1 бесплатный разбор для нового пользователя

## Файлы

| Файл | Назначение |
|---|---|
| `main.py` | точка входа |
| `config.py` | настройки из `.env` |
| `db.py` | SQLite: users / analyses / payments, атомарное списание и идемпотентная оплата |
| `tokens.py` | высокоуровневый API баланса (consume/refund/credit) поверх db.py |
| `payments.py` | инвойсы Telegram Stars (XTR) |
| `reader.py` | чтение канала через Telethon (reader-аккаунт) |
| `analyzer.py` | запрос к LLM (ollama или openai) |
| `prompts.py` | системный промпт «злого аналитика» |
| `handlers.py` | хендлеры бота: /start, /analyze, /balance, /buy, платежи |

## Запуск по шагам

1. Установка зависимостей:

```bash
pip install -r requirements.txt
```

2. Ollama + Llama (локально и бесплатно):

```bash
curl -fsSL https://ollama.com/install.sh | sh
ollama pull llama3.1:8b-instruct-q5_K_M
ollama serve
```

(или поставь `LLM_PROVIDER=openai` и `OPENAI_API_KEY` в `.env`)

3. Получи `API_ID` и `API_HASH` на my.telegram.org — это для **reader-аккаунта** (отдельный юзер-аккаунт, не бот).

4. Создай бота у @BotFather, получи `BOT_TOKEN`.

5. Настрой `.env`:

```bash
cp .env.example .env
# заполни BOT_TOKEN, API_ID, API_HASH
```

6. Первый запуск Telethon попросит номер телефона reader-аккаунта и код подтверждения; сессия сохранится в `reader.session`.

7. Старт:

```bash
python main.py
```

## Команды бота

- `/start` — знакомство, регистрация юзера
- `/analyze @channel` — разбор канала (10 токенов или бесплатный trial)
- `/balance` — баланс токенов и остаток бесплатных разборов
- `/buy` — пакеты токенов за Telegram Stars

## Что уже учтено в MVP (важно для денег)

- **Атомарное списание**: `UPDATE ... WHERE tokens >= ?` — нельзя уйти в минус.
- **Идемпотентность оплаты**: `pending → paid` условным UPDATE — повторный
  `successful_payment` не начислит токены дважды.
- **Откат при ошибке**: если канал не читается или LLM упала — токены/триал возвращаются.
- **Rate-limit**: не чаще 1 анализа в 30 сек + запрет параллельных анализов на юзера.
- **Резка длинных ответов** по границам строк под лимит Telegram 4096.

## Что доработать до продакшена

- **Очередь.** Сейчас анализ выполняется внутри хендлера (долгий LLM-запрос).
  Нужен Celery + Redis или простой asyncio.Queue с воркерами.
- **Postgres.** SQLite не выдержит нагрузки; замена — ~20 минут (обёртки db.py изолированы).
- **Модель.** Llama 8B даст базовое качество. Для «злого» стиля лучше 70B
  или fine-tune на 500–1000 хороших разборов.
- **Юридика.** Чтение чужих каналов через reader-аккаунт — серая зона.
  Безопаснее: только каналы, куда бот добавлен админом, или согласие владельца.
- **Платежи.** Stars — самый простой путь. Альтернативы: TON/USDT, ЮKassa,
  ручная выдача по чеку.
- **Хранение session-файла Telethon** беречь как пароль (2FA на аккаунте обязателен).
